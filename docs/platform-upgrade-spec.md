# 51job / 猎聘 / 鱼泡升级验收

沿用 2026-10-14 交接中的点击后核验路线：只通过浏览器正常导航和点击，不重放内部 API。

- 共用运行器负责 dry-run、Jev 标题与 JD 分流、7 天缓存、平台 ID 去重、状态日志和队列、节奏和 2 小时冷却。
- 平台适配器负责搜索 URL、卡片、详情身份/标题、按钮身份和可见成功状态。缺少身份不投。
- 提交前落盘 pending，再原生点击；未知结果和进程中断不重投。响应核验必须绑定本次职位和已校准的端点，未知端点 code=0 不算投递成功。可见成功状态必须是当前岗位点击后发生的变化。
- 检测风控立即退出；登录失效/简历向导停止并报告；每个 run 最多 60 个详情、有限搜索页，正常模式不提供加速或跳过冷却。
- 真投前须由用户明确授权。未校准平台默认禁止批量真投，只允许显式 --calibrate 配合 --count 1 做用户授权后的首单验证。
- 离线测试覆盖错误岗位、响应串扰、dry-run 零提交、pending 防重、风控优先和分页/标签生命周期。
- 当前在线结构、筛选参数与投递端点分别记录证据；不得把离线通过写成真实投递通过。
